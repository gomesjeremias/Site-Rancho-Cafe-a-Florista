# ☕ Rancho Café - A Florista - Site Responsivo

Este é um site responsivo para a cafeteria **Rancho Café - A Florista**, desenvolvido com foco em apresentar os produtos de forma atraente e moderna. O site conta com **modais interativos** que exibem mais informações ao clicar nos **cards dos produtos**.

## 🔍 Visão Geral

O site foi projetado para oferecer uma experiência fluida tanto em dispositivos móveis quanto em desktops. Ao clicar em um produto, um **modal** é exibido com informações detalhadas como descrição, ingredientes e preço.

## 🚀 Funcionalidades

- ✅ Layout totalmente responsivo
- ✅ Lista de produtos com imagens atrativas
- ✅ Modais interativos para detalhes dos produtos
- ✅ Menu de navegação fixo
- ✅ Estilo moderno e minimalista
- ✅ Código limpo e reutilizável

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (Flexbox e Media Queries)
- JavaScript
- (Opcional) Frameworks como Bootstrap ou Tailwind CSS
